PingRoom

A chat room where messages, who’s online and typing indicators update the instant they happen.

This is a portfolio project by Raghava, built with ASP.NET Core, SignalR and EF Core. Open it in two windows, join the same room, and watch them talk to each other. See the source on GitHub.

Join a room

Please don’t share passwords or personal details. Messages are saved, and anyone who joins the same room can read them. The server runs on a free tier, so the first connection can take up to 30 seconds.
